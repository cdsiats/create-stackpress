## Getting started

```bash
npm install
npm run generate
npm run push
npm run dev
```

The development server starts at <http://localhost:3000>. `npm run build`
creates the production build.

## Configuration

- `config/common.ts` exports the shared application configuration and the
  project-type feature configuration.
- `config/develop.ts`, `config/build.ts`, and `config/client.ts` bootstrap the
  Stackpress server for development, production, and client generation.
- `schema.idea` declares the application schema.
- The built-in `stackpress` plugin reads this configuration to generate API
  routes, admin surfaces, authentication, CSRF, sessions, roles, and
  permissions.

## Environment

Copy `.env.sample` to `.env` before starting the server and fill in the values
you need. Never commit `.env`.

## Structure

- `config/` holds application, feature, and database configuration.
- `plugins/app/` holds application routes and views.
- `plugins/store/` holds the database connection and populate logic.
- `public/` holds the logo, icon, favicons, and global styles.
- `schema.idea` holds the schema declarations.
